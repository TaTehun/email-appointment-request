// technical_highlights

FILTER
Five-Step Row Filter
Service type, non-portal customer, Initial at Stage 1, no requested date, and blank APPT Scheduling. Each step logs its count.
RECIPIENTS
Alias + City Match
Master short names map to contact-report names. Contacts are narrowed to addresses that contain the load's city; an empty city never matches.
DATES
Rail vs OTR Request Date
Rail loads ask for destination ETA + 1 day; OTR loads ask for the RDD itself. A non-date RDD or missing ETA ends in F with the reason.
GROUPING
One Mail per Load
Rows grouped by Load ID. A grouped row's comma-joined POs and quantities are split and paired in order.
WRITE-BACK
Send Time Without Sent Items
The send time is captured at send and written as the request D/T, so the bot never has to read the Sent Items folder.
SAFETY
Formula-Safe Write
Reads with data_only=True, writes through a second load by header name, so formulas and column order changes don't break it.

// error_handling

No Recipient
No contact row for the customer, or none at the load's city → F with the customer and city in the reason.
Missing Rail ETA
No destination ETA → no request date → F. The Load is listed in the Skipped file.
RDD Not a Single Date
OTR loads need one RDD; a blank or multi-value cell → F with the raw value in the reason.
Invalid Address
Every address must match the email pattern; duplicates are removed case-insensitively.
Send Failure
sender.send() returns False → F. Master columns are written only for successful sends.
Formula Columns
The write pass is a separate workbook load, so cached formula values from the read pass are never saved over formulas.

// dev_process · Claude Code Conversations · paraphrased from working sessions

Recipients From the Contact Report
TJ
Take the To list from the customer contact report, not a fixed list. Map the master's short customer name through an alias table, then keep only the contacts whose address contains the load's city. CC and BCC stay fixed, and the BCC is hidden from the customer.
C
resolve_recipients() applies the alias, filters by city, and falls back to every row only when no row has an address. An empty city is excluded from matching so it can't hit every address.
Widen to Over-the-Road Loads
TJ
Include FT loads too. Rail loads ask for destination ETA plus one day; FT loads ask for the RDD itself. If the date can't be computed, record F with the reason instead of sending a guess.
C
TARGET_SERVICE_TYPES is now {PN, PR, FT}. requested_date() returns (date, reason); a None date short-circuits to F before any mail is built.
Same Result Mail as the Portal Bots
TJ
After the run, send one result mail like the portal bots: the master attached, plus a Skipped file when any Load failed. No separate failure mail per Load. '(No Data)' in the subject when nothing was processed.
C
send_result_mail() copies the master under the shared naming rule, attaches the Skipped file built from failures, and switches the subject when nothing ran.
List Every PO in the Mail
TJ
Put each PO with its quantity in the body. Grouped rows hold the POs and quantities comma-joined, so split both and pair them in the same order. Drop the container line.
C
po_qty_pairs() walks every row of the Load and pairs the split lists by index; a missing quantity stays blank instead of shifting the rest.
